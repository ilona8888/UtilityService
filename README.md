# Калькулятор разницы коммунальных платежей (субсидированный vs полный тариф)
Приложение с графическим интерфейсом на JavaFX для расчёта разницы в стоимости коммунальных услуг при разных тарифах (субсидированный и полная стоимость) с учётом актуальных курсов валют от Национального банка.

## Назначение
**Программа помогает пользователю**:
- ввести объёмы потреблённых услуг (вода, газ, электричество и т. д.);
- автоматически подставить тарифы из файла tariffs.txt для двух сценариев: субсидированный и по полной стоимости;
- получить расчёт итоговой суммы и разницы между сценариями;
- конвертировать результат в нужную валюту на основе реального курса от Национального банка (REST‑запрос).

##  Технологический стек
**Язык**: Java 21 (JDK 21).
**GUI**: JavaFX 21 (javafx-controls, javafx-fxml) — интерфейс на FXML + CSS.
**HTTP‑запросы**: встроенный java.net.http.HttpClient (Java 11+).
**Обработка JSON:**:
- org.json:json;
- javax.json + реализация от GlassFish;
- json-simple.
**Чтение файлов**: java.nio.file (современный API для работы с файловой системой).

## Функциональные возможности

- **Ввод данных**: поля для объёмов потребления; тарифы подтягиваются автоматически из file.json.
- **Расчёт разницы**: автоматический расчёт итоговой суммы по каждому сценарию и разницы между ними.
- **Конвертация валют**: REST‑запрос к API Национального банка, получение актуального курса, конвертация результата.
- **Валидация ввода**: проверка корректности чисел, запрет отрицательных значений и пустых полей.
- **Отображение ошибок**: понятные сообщения при проблемах с файлом тарифов, сетью, неверным форматом или ошибкой API.
- **Изменение тарифов**: возможность обновлять тарифы и сохранения в файл file.json
